# Python-for-chemists
Free beginner Python notebooks for chemists and materials scientists: XRD, UV-Vis, photocatalysis, supercapacitors and machine learning.

## Lessons

| Day | Topic | Notebook | Data |
|-----|-------|----------|------|
| 1 | Plot an XRD pattern | [Python_for_Chemists_Day1_XRD.ipynb](Python_for_Chemists_Day1_XRD.ipynb) | [xrd.csv](xrd.csv) |
| 2 | Find XRD peaks automatically + crystallite size (Scherrer equation) | [Day02_XRD_peaks_Scherrer.ipynb](Day02/Day02_XRD_peaks_Scherrer.ipynb) | [MnFe2O4_xrd.csv](Day02/MnFe2O4_xrd.csv) |
| 3 | Band gap from UV-Vis DRS: Kubelka–Munk + automatic Tauc plot | [Day03_Tauc_band_gap.ipynb](Day03/Day03_Tauc_band_gap.ipynb) | [TiO2_DRS.csv](Day03/TiO2_DRS.csv) |
| 4 | Dye degradation kinetics: C/C₀ plot + rate constant k, R², half-life | [Day04_degradation_kinetics.ipynb](Day04/Day04_degradation_kinetics.ipynb) | [MB_degradation_absorbance.csv](Day04/MB_degradation_absorbance.csv) |
| 5 | Specific capacitance from GCD curves: IR-drop correction + rate capability | [Day05_GCD_specific_capacitance.ipynb](Day05/Day05_GCD_specific_capacitance.ipynb) | [GCD_sample_data.csv](Day05/GCD_sample_data.csv) |
| 6 | EIS: Nyquist + Bode plots, equivalent-circuit fitting (Rs, Rct, CPE, Warburg) with errors + in-situ EIS (Rct vs potential) | [Day06_EIS_Nyquist_fitting_insitu.ipynb](Day06/Day06_EIS_Nyquist_fitting_insitu.ipynb) | [EIS_single_spectrum.csv](Day06/EIS_single_spectrum.csv), [EIS_insitu_potentials.csv](Day06/EIS_insitu_potentials.csv) |
| 7 | CV b-value analysis + capacitive vs diffusion contribution (Dunn method) + capacity from CV | [Day07_CV_b_value_Dunn.ipynb](Day07/Day07_CV_b_value_Dunn.ipynb) | [CV_scan_rates.csv](Day07/CV_scan_rates.csv) |
